# Food Delivery App

A mobile app that lets users browse restaurants and menus, order food, and track their orders, with secure login.

## Why I built it
To practice building a complete mobile app from start to finish and to recreate the experience of popular food ordering apps.

## Features
- Login screen with user authentication
- Browse restaurants and food items
- Search and filter by category (pizza, burgers, drinks, etc.)
- Add items to cart and change quantities
- Place orders and view order history
- Data saved online with Firebase

## Technologies used
- **Dart**: programming language
- **Flutter**: framework for building the mobile app
- **Firebase**: handles login and stores user, menu, and order data

## What I learned
- Building a multi-screen mobile app UI with Flutter
- Adding user login with Firebase Authentication
- Managing a shopping cart and order flow
- Storing and retrieving data from a cloud database

## How to run it
1. Install Flutter (https://docs.flutter.dev/get-started/install)
2. Download this project and open it in VS Code or Android Studio
3. Run `flutter pub get` in the terminal
4. Connect a phone or start an emulator
5. Run `flutter run`
